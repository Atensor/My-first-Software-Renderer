# My-first-Software-Renderer
---

A software Rasterizer I wrote to learn the concept of rasterization.
I additionaly used this project to learn C++ and some of its concepts.

If I revisit Rasterizazion I probably will use the GPU and need to inform myself about the topic beforehand.

A renderd Scene with the Stanford Dragon, Suzanne and a cube


For the window i used SDL3 and for the Debug ui imgui with The SDL3 backend.

3D Objects need to be triangulated and be winded consistently to be properly parsed and renderd
